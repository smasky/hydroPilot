# SWAT 2012 模板

`version: swat` 是面向 **SWAT 2012** 工程的模板。你只需写一份简洁的、懂 SWAT 的配置，不需要手工指定每个定宽列的位置和文本文件的行偏移。HydroPilot 会在运行前把模板展开为标准 `version: general` 配置。

本文描述的是 SWAT 2012。SWAT+ 请参见 [SWAT+ 模板](swatplus.md)。

## 模板展开后是什么

| 方面 | 模板输入 | 展开后的 general 输出 |
|---|---|---|
| Writer 类型 | 隐式（模板内置 SWAT 知识） | `writerType: fixed_width` |
| Reader 类型 | 隐式（模板内置 SWAT 知识） | `readerType: text` |
| 参数位置 | 变量名 + HRU 过滤条件 | 按文件解析出的具体 line/start/width/precision |
| 序列行定位 | `id` + `period`（时间步长由工程 IPRINT 推导） | 计算出的 `rowRanges` |
| 序列列定位 | `variable` 名称 | 从 SWAT 变量数据库解析出的 `colSpan` |

模板展开由 `SwatTemplate.build_config()` 完成。运行时始终基于展开后的 `version: general` 配置执行。加载配置后，HydroPilot 会在源 YAML 旁边生成 `<stem>_general.yaml`，你可以直接查看展开结果。

## 配置结构

### `version`

```yaml
version: swat
```

### `basic`

与 general 模式字段相同。模板通过 `projectPath` 发现 SWAT 工程结构。

```yaml
basic:
  projectPath: E:\BMPs\TxtInOut
  workPath: ./work
  command: swat.exe
```

### `parameters`

两层设计：

- `design` — 优化器看到的变量（名称、边界、可选类型）。
- `physical` — 这些变量如何写入 SWAT 输入文件。

```yaml
parameters:
  design:
    - name: CN2
      bounds: [35, 98]
    - name: ALPHA_BF
      bounds: [0, 1]
    - name: GW_DELAY
      bounds: [0, 500]

  physical:
    - name: CN2
      mode: v
    - name: ALPHA_BF
      mode: v
    - name: GW_DELAY
      mode: v
```

当 `physical` 条目省略时，模板从 SWAT 参数数据库自动填入默认值（文件位置、宽度和精度）。

#### HRU 过滤

你可以用 `filter` 块限定参数作用于哪些 HRU：

```yaml
physical:
  - name: CN2
    mode: v
    filter:
      subbasin: [1, 3, 5]
      land_use: AGRL
      soil: "Haplic Luvisols"
```

过滤规则：

- 同一字段多个值 → OR（`subbasin: [1, 3, 5]` 匹配 1、3 或 5）。
- 不同字段 → AND（land_use 和 soil 必须同时满足）。
- `not` 块 → 排除匹配的 HRU。
- 无 filter → 作用于所有 HRU。

```yaml
filter:
  land_use: AGRL
  not:
    slope: "30-45"
```

#### 离散参数

```yaml
design:
  - name: landuse_code
    type: discrete
    bounds: [1, 3]
    sets: [1, 2, 3]
```

### `series`

SWAT 序列描述如何从 SWAT 输出文件（`output.rch`、`output.sub`、`output.hru`）中提取模拟结果。

```yaml
series:
  - id: flow
    sim:
      file: output.rch
      id: 62
      period: [2019, 2021]
      colSpan: [50, 61]
    obs:
      file: obs_flow_monthly.txt
      rowRanges:
        - [1, 36]
      colSpan: [1, 12]
```

关键字段：

| 字段 | 用途 |
|---|---|
| `sim.file` | SWAT 输出文件（`output.rch`、`output.sub` 或 `output.hru`） |
| `sim.id` | 河段/子流域/HRU ID（从 1 开始） |
| `sim.period` | 时间窗口：`[2019, 2021]`、`["2019-06", "2020-09"]` 或多段 `[[2019, 2019], [2021, 2021]]` |
| `sim.colSpan` | 变量的列范围 `[start, end]` |
| `sim.variable` | SWAT 变量数据库中的变量名（设置后自动解析 `colSpan`） |
| `sim.rowRanges` | 直接写入此字段可绕过 `id` + `period` 的行计算 |

时间步长不从 `sim` 块中配置。模板会根据 SWAT 工程的 `file.cio` 中 IPRINT 设置自动推导时间步长（0=月尺度，1=日尺度，2=年尺度）。校验器会拒绝 `sim.timestep`。

使用 `variable` 替代 `colSpan` 时，模板从 SWAT 变量数据库中查找列范围：

```yaml
sim:
  file: output.rch
  id: 62
  period: [2019, 2021]
  variable: FLOW_OUT
```

观测文件路径相对于配置文件所在目录解析：

```yaml
obs:
  file: obs_flow_monthly.txt
  rowRanges:
    - [1, 36]
  colSpan: [1, 12]
```

### `functions`、`derived`、`objectives`

结构与 general 模式相同：

```yaml
functions:
  - name: NSE
    kind: builtin

derived:
  - id: nse_flow
    call:
      func: NSE
      args: [flow.sim, flow.obs]

objectives:
  - id: obj_nse
    ref: nse_flow
    sense: max
```

## 工程发现

模板加载时会读取 SWAT 工程目录，提取以下元数据：

| 文件 | 读取内容 |
|---|---|
| `file.cio` | 模拟时段（起止年份、儒略日）、输出时间步长（IPRINT）、输出跳过年数（NYSKIP） |
| `fig.fig` | 子流域数量和 ID |
| `*.sub` | 子流域面积、纬度、高程、HRU 数量、HRU 文件列表 |
| `*.hru`（头部） | 每个 HRU 的土地利用、土壤、坡度等级 |

这些元数据用于：

- 计算序列提取的 `rowRanges`。
- 解析 HRU 级别的参数文件目标。
- 校验 `sim.id` 值是否在有效范围内。

## 内置函数

`NSE`、`KGE`、`R2`、`RMSE`、`MSE`、`PBIAS`、`LogNSE`、`sum_series`，以及外部 Python 函数。

## 适用范围

- **仅限 SWAT 2012。** 本模板面向 SWAT 2012 文件格式（file.cio、fig.fig、.sub/.hru 结构、固定宽度参数文件）。SWAT+ 请使用 [SWAT+ 模板](swatplus.md)。
- 模板生成 `writerType: fixed_width` 和 `readerType: text`。基于 CSV 的 SWAT 工作流不在此模板覆盖范围内。
